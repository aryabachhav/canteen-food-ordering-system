# Canteen Food Ordering System

## Project Description
A Python command-line application for ordering food from a canteen.

## Requirements
- Python 3.x

## Installation
1. Install Python.
2. Download/clone this repository.
3. Open the project folder in a terminal.

## Running the Project

python canteen_order.py

## Features
- Display food menu
- Select food items
- Enter quantity
- Calculate bill
- Apply discount
- Generate order summary
